# Toon (Alnasl)

A cartoon theme, bundled with Alnasl (`priv/theme_packs/toon`) and offered in
every build. The page is royal blue under a faint white grid; the content sits
on a cream sheet with a thick navy outline and a hard shadow; the rail is navy
with the current place as a yellow pennant; panels are stickers, buttons are
solid and squash when pressed, go-buttons are yellow and remove-buttons
salmon, and table headers get a yellow band and striped rows.

- Headings: Bangers; body: Nunito. Both are vendored as `.woff2` in `fonts/`
  (SIL Open Font Licence 1.1, see `fonts/OFL.txt`), so the theme works in a
  hall without internet.
- `dark: false`: the reading surfaces are light; the blue is only around them.
- Tiles, boards, clocks and the move list get outlines and never move. The
  rest switches its animations off when the computer asks for reduced motion.
